# 研究進捗


---

::title::
論文調査

::default::
1. <span class="font-bold">3D human pose estimation and action recognition using fisheye cameras: A
survey and benchmark</span>
    - 去年の姿勢推定およびジェスチャ認識手法のサーベイ論文
2. <span class="font-bold">Human Pose Estimation in Monocular Omnidirectional Top-View Images</span>
    - 魚眼かつ俯瞰視点用のデータセットを作成し、従来の骨格認識モデルでその有効性を示した
    - 局所的な平坦化をせずにそのまま骨格認識をしている
3. <span class="font-bold">FlyPose: Towards Robust Human Pose Estimation From Aerial Views</span>
    - 骨格の制約に基づく合成データセットを作成する手法を提案(魚眼ではない通常画角の話)
    - データセットの種類が少ない真上から/真下からの視点でのデータセットの生成

次に読む論文: <span class="font-bold">Multi-person 3D pose estimation from a single image captured by a fisheye camera</span>

::default::

::title::

- 動的ハンドジェスチャー認識
- 魚眼画像内の腕ベクトルの方向推定
